# Lesson 9: JavaScript Arrays & Strings

## 📚 Overview

In this lesson, you'll learn how to work with arrays and strings—two foundational data structures in JavaScript. You'll explore how to create, access, modify, and loop through arrays and strings, as well as how to convert between them and apply higher-order functions like `forEach()` and `map()`.

## 🔑 Key Concepts

- Creating arrays and strings
- Accessing and modifying elements
- Adding/removing with `push()`, `pop()`, `shift()`, `unshift()`, and `splice()`
- Using `.length`, `.split()`, and `.join()`
- Looping through arrays and strings with `for`, `for...of`, and `for...in`
- Using string methods like `toUpperCase()`, `replace()`, `includes()`, `trim()`
- Leveraging `forEach()` for side effects and `map()` for transformations

## 🎯 Learning Outcomes

By the end of this lesson, you will be able to:

- Loop through arrays and strings using different techniques.
- Convert between strings and arrays.
- Apply common string methods.
- Use `forEach()` and `map()` for array processing.
