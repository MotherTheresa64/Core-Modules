# Lesson 7: JavaScript Conditional Statements & Functions

## 🧠 Overview

In this lesson, you will explore how to control the flow of logic in your programs using conditional statements and reusable blocks of code called functions. Topics include:

- if, else if, and else statements
- Logical operators: `&&`, `||`, and `!`
- Ternary operators
- Switch statements
- Function declarations, expressions, and arrow functions

## 🔑 Key Concepts

- **Conditional Logic:** Make decisions using `if`, `else if`, `else`, and `switch`.
- **Ternary Operator:** A shorthand for `if...else`.
- **Logical Operators:** Combine conditions with `&&`, `||`, and `!`.
- **Functions:** Encapsulate logic into reusable code blocks.
- **Arrow Functions:** A cleaner syntax for writing functions.

## 🎯 Learning Outcomes

By the end of this lesson, you should be able to:

- Use conditional statements to direct program flow.
- Combine conditions with logical operators.
- Refactor logic into reusable functions.
- Use arrow function syntax for concise functions.
- Implement switch statements for multiple conditions.
