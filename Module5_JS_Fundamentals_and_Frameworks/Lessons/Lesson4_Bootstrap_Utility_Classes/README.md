# Lesson 4: Bootstrap Utility Classes – Faster Styling Without Custom CSS

## 📚 Overview
This lesson focuses on Bootstrap’s utility classes, which allow developers to apply styling directly in HTML without writing custom CSS. You’ll use spacing, color, alignment, border, and display utilities to create clean, responsive designs quickly.

## 🧠 Key Concepts
- What utility classes are and how they differ from custom CSS
- Margin and padding utilities (e.g., `mt-5`, `p-4`)
- Text styling utilities (`text-center`, `text-danger`, `fw-bold`)
- Background and border utilities (`bg-warning`, `border-success`)
- Display and visibility utilities (`d-block`, `d-none`)

## 🎯 Learning Outcomes
By the end of this lesson, you will be able to:
- Apply Bootstrap’s spacing and alignment utilities
- Use color and border utilities for layout and emphasis
- Enhance web pages with responsive and centered elements
- Avoid repetitive CSS by using inline utility classes
