# Optional Challenge: Bootstrap Admin Dashboard

## 📚 Overview
This project is a fully responsive **User Management Dashboard** built entirely with Bootstrap. It demonstrates core front-end skills including layout design, UI components, and user interaction—all without writing custom CSS.

## ✅ Features Implemented
- Fixed responsive navigation bar
- Dashboard section with stat cards
- User registration form with validation
- Styled table of users
- Utility classes for spacing, alignment, and color

## 🚀 Bonus Features (Optional)
- Search filter above the user table *(not implemented in starter)*
- Color-coded status indicators *(Active vs Inactive)*
- Sticky sidebar layout *(advanced option)*

## 🧠 Key Concepts Used
- Bootstrap grid system
- Utility classes (`mt-5`, `text-primary`, `shadow-sm`, etc.)
- Bootstrap cards, navbars, forms, and tables
- Responsive layout techniques
