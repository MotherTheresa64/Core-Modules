# Lesson 3: Bootstrap Components – Reusing Pre-Built UI Elements

## 📚 Overview
This lesson focuses on Bootstrap's pre-built UI components, which enable developers to rapidly create polished user interfaces without custom CSS. You'll explore buttons, cards, and navigation bars and learn to customize them using utility classes.

## 🧠 Key Concepts
- Purpose and benefits of Bootstrap components
- Pre-styled buttons, cards, and navigation bars
- Utility classes for customization (e.g., spacing, colors, sizes)
- Responsive behavior built into components

## 📂 Included Files

| File Name     | Description                                            |
|---------------|--------------------------------------------------------|
| `index.html`  | HTML page showcasing Bootstrap buttons, cards, navbar |

## 🎯 Learning Outcomes
By the end of this lesson, you will be able to:
- Use Bootstrap components to enhance webpages
- Apply and customize buttons, cards, and navbars
- Combine utility classes to fine-tune appearance and layout
- Build structured, responsive UI features quickly
