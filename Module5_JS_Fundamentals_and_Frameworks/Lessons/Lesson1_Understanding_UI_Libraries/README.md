# Lesson 1: Understanding UI Libraries & Introducing Bootstrap

## 📚 Overview
This lesson introduces UI libraries in modern web development, focusing on Bootstrap as a foundational CSS framework. Students will learn how to integrate Bootstrap using a CDN and apply its pre-built styling classes to enhance HTML elements like text and buttons.

## 🧠 Key Concepts
- Purpose and benefits of UI libraries
- Bootstrap as an example of a CSS framework
- Setting up Bootstrap via CDN
- Using Bootstrap utility classes (e.g., `text-primary`, `btn`, `container`)
- Enhancing structure and appearance without writing custom CSS

## 📂 Included Files

| File Name     | Description                                 |
|---------------|---------------------------------------------|
| `index.html`  | Main HTML file with Bootstrap integration   |

## 🎯 Learning Outcomes
By the end of this lesson, you will be able to:
- Define what a UI library is and explain its use in web development
- Set up Bootstrap in a simple HTML project using a CDN
- Use Bootstrap classes to style text and buttons
- Understand how pre-built frameworks increase efficiency and consistency
