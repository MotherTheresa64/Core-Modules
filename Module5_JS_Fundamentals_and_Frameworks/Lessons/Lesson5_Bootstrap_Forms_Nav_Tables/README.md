# Lesson 5: Bootstrap Forms, Navigation, and Tables – Enhancing User Interaction

## 📚 Overview
This lesson introduces key Bootstrap components for user interaction: forms, navigation bars, and tables. Students will build a registration form, implement a responsive navbar, and style a table for displaying structured data using Bootstrap’s built-in classes.

## 🧠 Key Concepts
- Bootstrap form elements and validation feedback
- Responsive navigation bars using `navbar`, `navbar-toggler`, and collapse behavior
- Styling tables using `table`, `table-striped`, and `table-hover`
- Using Bootstrap classes like `form-control`, `is-invalid`, `input-group`, and `table-dark`

## 📂 Included Files

| File Name     | Description                                  |
|---------------|----------------------------------------------|
| `index.html`  | Full webpage with form, navbar, and table    |

## 🎯 Learning Outcomes
By the end of this lesson, you will be able to:
- Use Bootstrap classes to create styled, accessible forms
- Add a responsive navigation bar to a webpage
- Display data using styled Bootstrap tables
- Integrate all three features on a single responsive webpage
