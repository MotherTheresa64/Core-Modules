# Lesson 6: JavaScript Basics and Syntax

## Overview
This lesson introduces fundamental JavaScript concepts such as variables, constants, data types, output methods, operators, and type conversion. You'll learn how JavaScript integrates with HTML and how to run scripts in both the browser and the terminal.

## Key Concepts
- `let`, `const`, `var`
- Data types: String, Number, Boolean, Null, Undefined, Object, Array, Function
- Output methods: `console.log()`, `alert()`, `document.write()`
- Operators: Arithmetic, Comparison, Logical
- Type Conversion and Type Coercion
- Template Literals and Commenting

## Included Files

| File         | Description                                      |
|--------------|--------------------------------------------------|
| `index.html` | HTML file demonstrating script linkage methods   |
| `main.js`    | JavaScript file used to practice core concepts   |

## Learning Outcomes
By the end of this lesson, you will:
- Understand the difference between internal, inline, and external JavaScript
- Be able to declare and use variables with different data types
- Use console logging and output methods for debugging and interaction
- Perform arithmetic and logical operations
- Convert and compare data types safely
