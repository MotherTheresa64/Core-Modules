# Knowledge Check: Bootstrap Basics, Utilities, Forms, and Components

## 📚 Overview
This project demonstrates my understanding of Bootstrap concepts covered in Module 5. It includes:
- A responsive navigation bar
- A registration form with layout and validation
- A Bootstrap-styled data table
- Responsive image and button utilities

## 🛠 Key Features
- Bootstrap CDN setup
- Container-fluid layout for responsiveness
- Grid-based form with validation
- Striped, hoverable responsive table
- Fluid and circular images using utility classes
- Buttons with responsive visibility
- Fully functional collapsible navbar

## 🚀 Technologies Used
- HTML5
- Bootstrap 5.3 via CDN

## 📁 Files
- `index.html`: Main webpage
- `assets/sample.jpg`: Example image for demonstration
