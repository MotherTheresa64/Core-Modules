# Lesson 2: Bootstrap’s Grid System – Structuring Responsive Layouts

## 📚 Overview
In this lesson, you’ll learn how to use Bootstrap’s 12-column grid system to build responsive layouts that adapt to different screen sizes. You’ll build a simple page using containers, rows, and columns, and apply responsive breakpoints to control layout behavior across devices.

## 🧠 Key Concepts
- Importance of responsive design
- Bootstrap grid system: containers, rows, columns
- Column width and the 12-column rule
- Responsive breakpoints: col-sm, col-md, col-lg, etc.
- Using layout utilities like `bg-light`, `text-white`, `p-4`

## 📂 Included Files

| File Name     | Description                                 |
|---------------|---------------------------------------------|

## 🎯 Learning Outcomes
By the end of this lesson, you will be able to:
- Explain why responsive design is important
- Use Bootstrap’s grid system to build structured layouts
- Apply responsive classes to ensure layout adjusts on different screens
- Extend a layout to include multiple columns with different breakpoints
