# Lesson 8: JavaScript Loops & Repetition

## 🧠 Overview

In this lesson, you will learn how to automate tasks with loops in JavaScript. Loops help reduce repetition and are essential for working with arrays, objects, and user-driven tasks.

## 🔑 Key Concepts

- **Increment/Decrement Operators:** `++` and `--` used in pre/post forms.
- **for Loops:** Traditional loop using a counter.
- **for...of Loops:** Loop through iterable values (arrays, strings).
- **for...in Loops:** Loop through object keys or array indices.
- **while Loops:** Repeat while condition is true.
- **do...while Loops:** Like while, but runs at least once.
- **Nested Loops:** Loop inside another loop.
- **break / continue:** Control flow inside loops.

## 🎯 Learning Outcomes

By the end of this lesson, you should be able to:

- Create and control different types of loops.
- Avoid infinite loops with correct conditions.
- Use `for`, `while`, `do...while`, and enhanced loops effectively.
- Implement nested loops for complex iterations.
- Use `break` and `continue` to manage loop flow.
