# Lesson 1: Component Lifecycle

## Overview
This lesson introduces the React component lifecycle in the context of functional components using hooks. You’ll explore the three main lifecycle phases—Mounting, Updating, and Unmounting—using `useState` and `useEffect` to manage side effects and component behavior.

## Key Concepts
- Lifecycle phases: Mounting, Updating, Unmounting
- Functional components vs class components
- `useState` for managing component state
- `useEffect` for managing side effects and lifecycle behavior
- Conditional rendering
- Component mounting/unmounting

## Included Files

| File Name             | Description                                      |
|----------------------|--------------------------------------------------|
| `App.jsx`            | Main component that controls rendering behavior  |
| `components/PokemonList.jsx` | Fetches and displays Pokémon using hooks      |
| `App.css`            | Basic styling for the Pokémon list               |

## Learning Outcomes
By the end of this lesson, you will be able to:
- Describe the three phases of the React component lifecycle
- Use `useState` and `useEffect` to manage state and lifecycle logic
- Fetch external API data in a React component
- Conditionally render components
- Identify when components mount, update, and unmount
