# Lesson 2: JavaScript DOM

## Overview
In this lesson, you'll learn how to use JavaScript to access and manipulate the DOM (Document Object Model). The DOM allows JavaScript to dynamically read and modify HTML elements, adjust their attributes and styles, respond to user events, and create or remove elements from the page. These are essential skills for creating dynamic and interactive web applications.

## Key Concepts
- DOM Tree Structure
- Element Selection (ID, class, tag, CSS selectors)
- Modifying Content with `.textContent` and `.innerHTML`
- Updating Attributes and Styles
- Creating and Removing Elements
- Handling Events with `addEventListener()`
- Separating HTML structure from JavaScript behavior

## Learning Outcomes
By the end of this lesson, you will be able to:

- Select elements from the DOM using various methods (`getElementById`, `querySelector`, etc.)
- Modify HTML element content, attributes, and styles using JavaScript
- Respond to user actions such as clicks and keypresses using event listeners
- Create, append, and remove HTML elements dynamically
- Write cleaner, more maintainable code by separating JS from HTML
