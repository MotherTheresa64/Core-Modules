# 🐾 PokeAPI Integration App

This is a simple React application that allows users to search for a Pokémon by name or ID and fetch basic information using the [PokeAPI](https://pokeapi.co/). It demonstrates API integration, React state management, and DOM manipulation using `useState` and `useEffect`.

---

## 🧠 Overview

This app was built as a Coding Temple assignment to practice:
- Consuming APIs using Fetch and Async/Await
- Managing state with React's `useState`
- Conditional rendering and error handling in React
- Basic component composition

---

## 🚀 Features

- Search Pokémon by name or ID
- Displays Pokémon name, sprite, and type(s)
- Graceful error handling for unknown Pokémon
- Responsive, minimalist design
