# Lesson 1: JavaScript Objects

## Overview
In this lesson, you'll explore JavaScript objects—how to define them, access and update their properties, add methods, and use objects for structured data. You'll also dive into more advanced features such as nested objects, constructor functions, and built-in objects like `Math` and `Date`. These foundational skills are essential for working with real-world JavaScript applications and frameworks like React.

## Key Concepts
- Object Literal Notation
- Accessing & Modifying Properties
- Adding Methods and Using `this`
- Nested Objects and Deep Access
- Constructor Functions for Reusability
- Iterating Over Object Keys/Values
- Built-in Objects: `Math` and `Date`

## Learning Outcomes
By the end of this lesson, you will be able to:

- Create and update JavaScript objects using literal and constructor syntax
- Add and call methods on objects using `this`
- Work with nested object properties and structure data logically
- Iterate over an object's keys and values dynamically
- Utilize built-in utility objects like `Math` and `Date`
- Build scalable object templates using constructor functions
