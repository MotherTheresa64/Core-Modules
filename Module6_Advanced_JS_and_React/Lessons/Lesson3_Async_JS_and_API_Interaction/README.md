# Lesson 3: Async JavaScript and API Interaction

## Overview
In this lesson, you'll learn how JavaScript handles asynchronous operations using callbacks, promises, and async/await. You'll also work with APIs by making HTTP requests using `fetch`, handling errors, and managing multiple requests in sequence or in parallel.

## Key Concepts
- JavaScript Callbacks
- setTimeout and setInterval
- JavaScript Promises
- Fetch API for HTTP requests
- Async/Await syntax
- Error handling using try...catch
- Sequential and Parallel API calls with `Promise.all`

## Included Files

| Filename                  | Description                                                        |
|--------------------------|--------------------------------------------------------------------|
| `callback_example.js`    | Demonstrates the use of a basic callback function                   |
| `timeout_interval_demo.js`| Uses setTimeout and setInterval to show time-based async behavior  |

| `sequential_api_calls.js`| Makes multiple dependent API calls in sequence                      |

| `error_handling_example.js`| Demonstrates error handling when API endpoint is invalid          |

## Learning Outcomes
By the end of this lesson, you will be able to:

- Explain the difference between synchronous and asynchronous JavaScript
- Implement callbacks, promises, and async/await in your code
- Use `fetch()` to retrieve data from APIs
- Handle errors in asynchronous code using try/catch
- Manage both sequential and parallel API calls efficiently
